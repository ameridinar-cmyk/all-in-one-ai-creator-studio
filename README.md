# All-in-One AI Creator Studio

Free mobile-friendly starter for planning Reels and YouTube Shorts.

## Features
- Reel idea generator
- Script draft builder
- Thumbnail prompt builder
- Five-scene planner
- Caption helper

## Publish with GitHub Pages
1. Open Settings → Pages.
2. Choose Deploy from a branch.
3. Select branch `main` and folder `/(root)`, then Save.
4. Wait for the Pages URL.

These are browser-side templates, not live AI generation. Never put private API keys in public frontend code. Verify facts and use media you have permission to publish.
